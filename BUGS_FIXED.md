# Bugs fixed

Format: file – what was wrong – how it was fixed – test(s) (all in `tests/`).

How the tests were produced: the first batch (`test_utils_functions.py`) was written against the *intended*
behaviour before the code was changed and failed on the old code (for example the query-count and `get_level` tests).
For the views that were rewritten wholesale, the tests encode the correct behaviour and were written together with
the rewrite; where a bug could only be reproduced by a specific input, that input is a separate test case. Bugs that
depend on the server time zone (marked *tz*) have no failing-first test, they are covered by behaviour tests only.
